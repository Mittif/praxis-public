# 解析引用与错题分页

两站使用固定选项 ID 判分。解析中的原题字母由服务端编译成引用，再由界面根据实际展示的选项顺序生成当前字母。例如原题 A 的内容显示为 B 时，“选项A正确”显示为“选项B正确”。多项引用保留原文顺序，以顿号分隔。

## 保留原文和历史

- `explanation` 始终保留原始解析，沿用现有换行规范化；映射不写回题库或历史数据库。
- 已作答结果和授权的查看答案接口附带 `explanation_mode`、`explanation_parts`。文本片段使用 `type: text` 和 `text`；选项引用使用 `type: option_ref`、`option_ids` 和 `source_text`。拼接文本与 `source_text` 可以还原原解析。
- 主站反馈、本轮错题回顾、错题本，以及极简版刷题反馈、临时查看答案、背题和错题本共用显示规则。未作答题目和目录不携带解析片段。
- 主站错题展开时按需读取 `/api/v1/mistakes/{qid}/review`，只返回当前账号最近一次作答的快照。极简版继续读取共用作答记录；相同内容可以使用当前显示顺序，题干、材料或选项内容发生修订时使用保存的快照。
- 极简版恢复会话后查看答案使用 `session_id` 指定会话快照，不从新题库替换旧解析；跨账号会话不可访问。
- 映射后的解析可展开查看原始解析与原题／当前选项对照。缺失来源信息、无法确认用途的字母和不完整片段均回退原文，并明确提示对照阅读。已有会话不重排。

## 识别范围

规则识别“选项A”“A选项”“A项正确”“ACD说法均错误”“A、C正确”“正确答案为B”等明确引用。英文单词、公司代号和明确公式变量保留原文。不确定的独立字母会进入复核报告；这类题的新会话保持原选项顺序，不冒险改写。规则不调用运行时模型。

全量审计只读题库，报告仅含题目 ID、偏移量和原因，不包含题库正文，默认保存在 Git 忽略目录：

```sh
.venv/bin/python scripts/audit_explanations.py
```

## 错题分页

两站错题本宽度大于 760px 时每页 12 题，手机宽度时每页 5 题。支持上下两处上一页／下一页、页码选择、题目范围和总数提示。筛选待巩固／已巩固或科目时回到首页；宽度变化按当前条目位置换算页码，数据减少时自动限制到有效页。分页只影响展示，不截断错题巩固的练习范围或统计记录。

```sh
.venv/bin/python -m pytest -q
npm run test:presentation --prefix frontend
npm run build --prefix frontend
```
