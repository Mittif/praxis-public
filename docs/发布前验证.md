## 隐私与发布边界

- 扫描当前待提交文件和全部可达 Git 历史：未检出匹配的私钥、凭据 URL、访问令牌、本机实例密钥及受保护文件路径。
- 对文本文件补充检查实际本机主目录路径、邮件地址、内网地址及密钥赋值模式，未检出匹配内容。
- 前端生产产物检查未检出匹配的本机实例密钥或凭据模式；不生成 source map。
- 检查当前 API 运行镜像的应用目录，未发现开发数据库、实例 `.env`、私钥或备份文件。
- 本机 `.env`、SQLite 数据库及临时部署私钥使用 600 权限，并位于 Git 忽略范围内。备份、依赖、构建产物、浏览器追踪和发布临时目录不提交 Git。
- Compose 支持 `BIND_ADDRESS`，可在服务器已有 HTTPS 反向代理时仅绑定环回地址，避免额外对外开放容器端口。
- 部署包从最终提交中按运行文件允许列表生成，并解压检查每项内容；不包含 `.git`、开发数据库、备份、原始 PDF、截图、日志、本机实例配置或 SSH 密钥。
- `.env.example`、`compose.yaml`、`Caddyfile`、Dockerfile 等属于公开部署模板；服务器实例密钥应在服务器本地生成或保留，不由本机配置复制。

python3 scripts/check_secrets.py
