## 核对的核心约定

- 判分使用固定选项 ID；重复提交不重复累计事件，历史内容使用会话快照。
- 解析引用保留原文；无法确认用途的字母采用保守回退，不使用全局字符替换。
- 主站回看收起后仅显示已选／正确项，选项顺序与标签仍来自当前快照，颜色区分错选与正确项。
- 简洁模式的临时答案不提交作答、不切换学习模式；迟到响应不会跨题或退出账号后重新显示。
- 公开展示使用自编演示数据；当前 README 说明了旧视觉素材与现有界面的版本差异。

## 尚需维护的边界

- 登录频率限制为单进程内存实现；扩展为多副本时需统一限流与可信代理配置。
- 历史快照和答题事件聚合适合当前规模，大量记录需要进一步优化查询和加载。
- 题库自动化只校验结构、空白整理和明确引用，内容正确性与资料授权仍需人工确认。

本记录描述源码候选的检查范围，不代表对任意部署实例的渗透测试或长期安全保证。部署行为取决于实际运行的版本与配置。
