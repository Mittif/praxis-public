# 新野兽派交互与视觉迭代

分支：feat/interaction-upgrade。保留 main 的 1.0 基线。

## 统一设计语言

以“练习手帐”为主题。淡黄绿页面、米白纸张、淡紫分区、粉色主动作、青色选中状态。答对使用薄荷绿、答错使用浅珊瑚色，同时提供符号与文字反馈。边框2px、硬阴影4–5px，不增加玻璃模糊和霓虹光效。

中文使用系统无衬线字体（优先苹方/Noto Sans SC/微软雅黑），不请求外部字体。主标题32–60px，页面标题29–43px，题干桌面23px/手机20px，选项桌面17px/手机16px，解析15px/14px。正文行高1.8–1.9。数字与编号使用等宽字体和等宽数字，说明文字与正文明确区分。

首页、登录、错题本、历史、账号、答题和总结页共用标签、编号、留白与边框规则。纸张票据、胶带和撕边集中在装饰区及反馈区。答题操作栏放入内容流，避免覆盖长解析；手机题集卡片紧凑排列。

## 动效规则

- 保留原有页面淡入、选项按压、错误轻振及切题位移。
- 导航选中底板弹簧滑动；题集卡片分批进入、悬停轻抬与图标轻转。
- 选中选项触发6枚像素短促散开；答对触发14枚；完成一轮触发26枚。
- 粒子只用transform/opacity，不接收鼠标事件，最多1.4秒后从DOM移除；不会持续循环，也不会在刷新判题页时重播答对奖励。
- 判题纸张展开，答案纸条轻弹，底部为矢量撕边；解析保持静止以便阅读。
- 弹窗有进入/退出过渡、焦点锁定、Escape关闭和返回入口焦点。
- 尊重系统减少动态效果设置，关闭粒子及装饰性CSS动画，保留完整状态和文字。

## 选项乱序与答案对齐

- 每次创建练习，将抽中的题目复制为会话快照，随后分别打乱选项。
- 每个选项保留稳定id；label为本轮显示字母，source_label为原题字母。前端显示label，提交id，后端按id集合判分。
- 响应保留answer/selected固定ID，同时增加answer_labels/selected_labels，方便客户端显示。
- 本轮顺序、正确答案、解析与材料保存在同一快照；刷新、暂停、历史回看与更新题库均不重新排列本轮选项。
- 旧会话缺少label时沿用原id，继续兼容。
- 多选答案提示按本轮显示顺序排列；历史总结也读取对应会话的标签映射。
- 不自动替换解析中的字母，避免误改公式或变量。若标签变化，提供可展开的“原题→本轮”选项对照；案例原页也提示按下方本轮选项作答。
- 常见“以上都正确”“A和B均正确”等依赖顺序的题保留原顺序。维护者可对任何特殊题设置 `shuffle_options: false`，明确关闭乱序。自动规则无法代替题库内容审核。

## 验证

浏览器测试包含原有注册/作答/续刷/退出流程，以及粒子限时移除、刷新不重播奖励、减少动态效果、弹窗焦点与关闭、320/390/1440宽度巡检、稳定ID与显示字母交叉映射。题目数据使用测试拦截构造，不修改管理员账号。

后端测试验证题库原对象不被修改、单选/多选固定ID判分、乱序标签映射、顺序依赖保护、会话快照不变、旧会话兼容和原有账号及练习规则。

当前验证结果：TypeScript与Docker生产构建通过；13项后端测试、8项浏览器测试通过。
浏览器用例已在本机Docker入口执行，覆盖320、390、1440宽度。真实API另行验证了随机选题后的固定ID判分与刷新保序。
