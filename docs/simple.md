# 极简版 `/simple`

极简版按照用户提供的刷题 HTML 保留蓝白卡片、920px 内容宽度、筛选区、题号网格、刷题／背题／错题本／统计、夜间模式和快捷键。网页标题和页头统一为 `Praxis · 简洁模式`。它是独立的轻量页面入口，不加载主站的 React 界面与样式。

## 与主站共用的数据

- 复用主站登录 Cookie、账号隔离、题目 ID、题库、会话快照、固定选项 ID 判分与答题事件。极简版不在浏览器本地另存答题数据库。
- 极简版答题进入主站历史、覆盖进度与错题统计；主站作答也会更新极简版。错题遵循主站连续答对两次后巩固的规则。
- 收藏使用共用的 `question_bookmarks` 表，主站作答页与极简版均可操作。
- 页面切换、窗口重新获得焦点或同源页面通知时刷新数据；不同设备从同一账号接口读取记录。
- 题号跳转允许乱序作答，但主站会话进度始终指向首个尚未完成的位置。重复提交保留原有判分，历史事件不覆盖。

## 保留的操作

- 单选点击即提交，多选勾选后提交；支持 `A–E`、`1–5`、`Enter`、左右方向键、`S` 收藏、`R` 重做。
- 按题集、科目、题型、卷别、模块、未答、待巩固、收藏筛选，支持搜索、随机与题号跳转。
- 筛选区默认收起，点击“题目筛选”展开；收起时展示当前筛选摘要，翻题和切换模式保留展开状态。
- 刷题、背题的上一题／下一题、键盘翻题及题号跳转保留当前滚动位置；背题加载解析时预留卡片高度，避免手机页面短暂缩短而跳动。新题比原题短、页面高度不足时由浏览器保持在最近可用位置。
- 背题模式支持遮盖答案，查看答案不创建答题事件。
- 刷题时“看答案”只在当前题下临时展开答案与解析，不切换模式、不提交作答；单选和多选均可查看，多选已勾选的选项保留。再次点击可收起，翻题、切换模式或账号后自动隐藏。
- 翻题、模式切换、筛选展开与收起、题号网格、临时答案、判分反馈和操作提示提供短时过渡；动画不触发滚动或延迟提交，并响应系统“减少动态效果”偏好。
- 导出当前账号记录，兼容导入旧版记录。导入只补充主站尚无作答的可匹配题目，答案由服务端重判；已有主站记录优先保留。无法匹配的记录跳过。
- 原版的“清空全部记录”改为“重置筛选”，“清空错题”改为查看已巩固；重做新增作答，不删除主站历史。
- 错题本电脑每页 12 题、手机每页 5 题，支持上一页、下一页和页码跳转；展示选项、答案和按当前选项同步的解析，保留历史快照与原文对照。详见 [解析引用与错题分页](explanation-references.md)。

## 可选模块标签

`scripts/build_simple_metadata.py --reference <参考HTML路径>` 可将题干、选项和来源均可确认的参考题目映射到主站 ID，生成本地 `data/simple-metadata.json`。该文件只补充显示标签与旧记录 ID 对照，不导入或修改参考答案。它与原始参考 HTML 均不进入公开仓库；缺少文件时仍可练习，未匹配题目显示“未分类”。

## 运行与验证

按 README 准备题库并启动应用后访问 `/simple`。前端 Vite 同时构建主站和 `simple/index.html`，Caddy 将该路径映射到极简版入口。

```sh
.venv/bin/python -m pytest -q
npm run build --prefix frontend
BASE_URL=http://localhost:8080 npm run test:e2e --prefix frontend
```

新增迁移仅增加收藏表；部署继续使用现有 PostgreSQL 数据卷，不新建另一套用户或答题记录。

## 题库版本与续接

自动续接要求题目范围和题库版本都匹配，避免新目录与旧会话的答案混用。旧会话仍可通过历史入口或会话 ID 显式恢复，并使用原始快照；缺少版本标记的早期会话不参与自动续接。
