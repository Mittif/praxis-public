# 主站答题与解析布局

主站答题页保留纸张、墨色边框和现有配色，以题目阅读、提交反馈和固定操作位置组织布局。判分继续使用固定选项 ID，历史题目与作答记录保留原始快照；解析引用与跨站错题回看见 [解析引用与错题分页](explanation-references.md)。

联调时已将原有 `simple` 分支合并到 `main`（`9afd532`），恢复 `/simple/` 页面、构建入口及共享接口，并保留题库换行修正。这部分保留极简版已有界面；当前新布局仍只用于主站。

## 阅读阶段

- 作答时居中阅读，最大宽度 820px。题干桌面 20px／手机 18px，选项 17px／16px，间距固定。普通题尽量一屏展示，长题和案例材料使用页面自然滚动。
- 提交后，1024px 及以上使用约 300px 左侧题目回看区和右侧解析；窄屏上下排列。默认展开完整题干、全部选项和材料，不再显示“你的选择／正确答案”文字摘要。收起后保留题干摘要和已选／正确选项的并集，重合选项只显示一次，保留当前选项字母、完整内容和红绿状态。电脑选项竖排，760px 及以下两列横排，奇数末项铺满一行；新提交及刷新已答题时均默认展开。
- 回看题干与选项使用固定的 15px／14px，解析使用 16px／15px。手机回看区减少边距、隐藏重复的足迹统计；反馈符号缩至 32px，结论字号为 18px／17px，收紧标题、解析及原文对照之间的留白。篇幅不参与字号或间距计算，完整题目和解析仍可阅读。

## 操作与动效

- 底部操作栏通过 Portal 挂载到 body，检查与继续复用同一按钮位置，适配安全区。ResizeObserver 测量栏高，将避让空间加到页面容器外的 body 底部内边距；离开练习或完成后移除。
- 底部说明改为“喜欢简单些？切换到极简版”和 `simple ↗` 链接，指向 `/simple/`，贴齐 main 内部底边，外框保持封闭。滚动到底时外框底部距固定操作栏上沿留 22–38px（窄屏 24px），正文末端只保留固定的 24px 留白，避免重复预留操作栏高度。提交错误提示浮在操作栏上方，长题滚动时也能看到，按钮位置不变。
- 题目区用实际宽度、字号和折叠高度过渡，位置动画不缩放正文。收拢约 620ms，反馈淡入 560ms，解析错后 90ms；使用 `cubic-bezier(.42,0,.35,1)`，错误反馈不抖动。
- 反馈右栏在横向过渡中维持最终阅读宽度，避免被挤成细长文本。操作栏独立于动画容器，不随页面滚动。
- 新提交后，布局过渡完成时检查有效视口，手机短题优先同屏保留题目回看与解析开头；内容较长时仍定位解析标题。下一题定位题目区起点。刷新已答题、后台查询刷新、展开摘要不重复触发该定位或奖励。
- 请求同步锁、防连击 300ms 与反馈过渡锁防止重复操作。失败保留勾选，下一题请求成功但刷新失败时重试仍使用同一索引，不跳题。离开练习会移除操作栏并停止旧页面的定位。
- 减少动态效果时直接切换布局和定位，保留 300ms 防连击保护。

## 验证

`npm run build --prefix frontend` 构建并检查类型。`frontend/e2e/practice-focus.spec.ts` 覆盖 1440×900、1024×768、390×844、320×568 的按钮坐标、两阶段布局、长内容、案例图、失败重试与刷新恢复。

离线 React 集成验证使用真实构建产物、内存 API 和模拟几何值，无网络、无浏览器，不代表真实视觉验收。浏览器站点权限仍阻止自动访问时，应明确报告未执行的视觉检查，使用本地人工预览确认间距、真实坐标和动画手感。
